# 既存の A/B 資料（PDF）を直すときの差分リスト（Issue #106）

最終更新: 2026-10-13

**A/B 資料の PDF は、リポジトリにも開発機にも無く、中身を読めていない。**そのため、このリストは「PDF のどこを直すか」ではなく、**「資料が古くなっていそうな点を、実装の側から並べたもの」**。オーナーが PDF と見比べて、当てはまる行を直す。PDF を渡してもらえれば、ページごとの差分に書き直す。

- 資料を更新するかどうか、いつ更新するかは、オーナーが決める。
- 更新した PDF は、相手の会社名などが入るなら、公開のリポジトリに置かない。

## 2. 資料に書いてあったら、弱める・消す表現

事実と合わない、または認証・診断と誤解される表現。

| 表現 | なぜ | 直し方 |
|---|---|---|
| 「エンタープライズ級」「金融機関レベル」「万全」 | 根拠を示せない。開発の目標（`CLAUDE.md` の言い回し）であって、外に約束できる水準ではない | 行っている対策を、具体的に書く |
| 「ISMS 準拠」「ISO 27001 相当」「P マーク相当」「取得予定」 | 未取得。予定も決まっていない | 「未取得」。必要なら「要否は検討中」 |
| 「診断済み」「脆弱性なし」「ペネトレーションテスト実施」 | 第三者の診断は受けていない。自動の検査は診断ではない | 「自動の検査を、変更のたびに実施。第三者の診断は未実施」 |
| 「SOC 2 / ISO 27001 取得済みの基盤」 | 各社の認証を、このサービスのものと読まれる | 「利用している各社の認証は、各社のもの」と添えるか、書かない |
| 「24 時間 365 日の監視」「即時に対応」 | 運営者 1 名。通知のルールも未設定 | 「エラーを集めている。通知は設定の途中」 |
| 「データは国内に保管」 | データベースは東京だが、配信・エラーの報告などは日本の外 | 「データベースは東京。日本の外のサービスも使う」と、一覧を付ける |
| 「すべて暗号化」「独自の暗号化」 | 各社の既定の暗号化だけ。自分で鍵を管理していない | 「通信は TLS。保存は各社の既定の暗号化」 |
| 「削除すれば完全に消える」「即時に消去」 | 写真は残る。バックアップに最長 14 週、監査ログは 400 日 | 残るものを書く（[data-inventory.md](../privacy/data-inventory.md) §5） |
| 「写真は認証された人だけが見られる」 | 公開側の写真は、URL を知っていればログインなしで開ける | 「タイムラインは招待された人だけ。写真のファイルは、推測しにくい URL で配信」 |
| 「位置情報はすべて除去」 | 写真はそうだが、動画は位置情報がついたまま（Issue #29） | 「写真の原本は非公開。公開用は EXIF を除く。動画は未対応」 |
| 「稼働率 99.x%」「SLA」 | 定めていない。測ってもいない | 書かない |
| 「マルチテナント」「複数の式に対応」「SSO 対応」「権限の細分化」 | 無い（1 つの式の専用。検討中） | 「検討中」 |
| 「鍵レス（キーレス）で運用」 | 方針まで。本番はサービスアカウントの鍵 | 「置き換えを予定（移行は 2027-02 末まで）」 |
| 「コードレビューを実施」 | 人のレビュアーは運営者だけ | 「PR と自動の検査。第三者のレビューは無い」 |

## 3. 資料に足したほうがよいこと（無ければ）

- **前提の一文:** 個人 1 名の運営、未取得・未実施、法人への提供の実績は無い（[security-overview.md](security-overview.md) の冒頭）。
- **「できていないこと」の表**（[security-overview.md](security-overview.md) §4）。隠すより、先に出す。
- 外部のサービスの一覧と、それぞれに渡る情報（[subprocessors.md](../privacy/subprocessors.md)）。
- AI のサービスに送るもの（顔の検出の写真、管理者の AI の試験での本名）。
- ホスティングが、いまは非商用のプランであること、提供の前に変えること（[commercial-readiness.md](commercial-readiness.md) §1）。
- 資料の「時点」（日付）。実装は変わるので、日付の無い資料は出さない。

## 4. 構成図

法人向けの概要には、[security-overview.md](security-overview.md) §2 の図（`CLAUDE.md` の構成図を、法人向けの言葉に直したもの）を使う。PDF の図と違うところがあれば、次を確かめる。

- Vercel の手前に Cloudflare のプロキシを置いていない（DNS だけ）。写真の配信（R2）だけが Cloudflare を通る。
- 写真の置き場所は 2 つ（公開用と、非公開の原本）。EXIF を落とすのは Worker（ブラウザではない）。
- 音声合成は Modal（ElevenLabs ではない）。
- 監査ログは Firestore と、GCS の写し（ロック済み）の 2 か所。
