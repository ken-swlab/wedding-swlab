### プライバシーポリシー

【新郎新婦の名前、または「新郎新婦」】（以下「私たち」）は、結婚披露宴（【日付】）のために用意したこのサイト（以下「本サイト」）で、ゲストのみなさまからお預かりする情報を、次のとおり取り扱います。

#### 1. 運営者

本サイトは、【新郎新婦の名前】が個人で運営しています。お問い合わせ先は、9 をご覧ください。

#### 2. お預かりする情報

**LINE でログインするとき**

- LINE のユーザー ID、表示名、プロフィール画像
- 取得するのは、LINE がログインのために発行する情報（ID トークン）に含まれる、この 3 つだけです。**友だちのリスト、トークの内容、メールアドレス、電話番号は取得しません。**本サイトから LINE にメッセージを送ることもありません。

**ご回答いただくとき**

- お名前（姓・名）とふりがな
- 出欠と、挙式へのご参加
- お酒をどれくらい飲むか（5段階）
- お車代のご希望の有無
- 食物アレルギーの有無と内容
- 備考・連絡事項
- ニックネーム、ひとこと、アイコン画像（設定した場合）

**投稿するとき**

- 写真・動画、本文、コメント、いいね、思い出のエピソード

**オープニング（招待状を開いたときの演出）で**

- リアクションタイム（合図から指を離すまでの時間）。記録するのは最初の 1 回だけです。スキップした場合は記録しません
- 写真に記録された情報（撮影日時・位置情報など）。高画質の原本をお送りいただいた場合、原本は非公開の場所に保管し、ほかのゲストに見える写真からは、これらの情報を取り除きます。

**自動的に記録されるもの**

- 操作の記録（いつ・どの操作をしたか。入力された内容そのものは記録しません）
- 接続元の IP アドレス（不正な利用を防ぐため。操作の記録には、元に戻せない形に変換して残します）と、ブラウザの種類
- エラーの記録（お名前やご回答の内容は含みません）

**写真に写っている顔について**

- 投稿された写真から、顔の位置を自動で検出します。
- 新郎新婦が「この顔はこの方」と確認したものについて、ほかの写真でも同じ方を見つけられるよう、顔の特徴を数値にしたデータを保存します。
- 【この処理を望まない方は、9 の窓口までお知らせください。／（選ぶ手段を用意する場合は、その方法）】

#### 3. 利用する目的

- 披露宴・二次会の出欠の確認、席とお料理（アレルギーへの対応）・飲み物の準備、会費の計算
- ご本人の確認と、招待した方だけが見られる状態を保つこと
- 写真・メッセージを、ゲストのみなさまと共有すること（会場のスクリーンへの投影を含みます）
- 写っている方ごとに写真を整理し、【エンディングムービーなど】の演出に使うこと
- 不正な利用の防止、障害の調査

上の目的のほかには使いません。広告や、第三者への販売には使いません。

#### 4. ほかのゲストに見えるもの・見えないもの

| 情報 | 見える人 |
|---|---|
| ニックネーム、ひとこと、アイコン画像 | 承認されたゲスト全員 |
| 投稿（写真・本文）、コメント | 投稿のときに選んだ範囲のゲストと、新郎新婦。範囲によっては、会場のスクリーンにも映ります |
| 「新郎新婦あて」の投稿 | 投稿したご本人と、新郎新婦だけ |
| **お名前、ふりがな、LINE の表示名、出欠、お酒の量、お車代のご希望、アレルギー、備考** | **ご本人と、新郎新婦だけ**（ほかのゲストには見えません。ただし、お酒で「大量」を選んだ方には「酒豪」のタグが付き、タグはほかのゲストにも見えます） |
| リアクションタイム | 承認されたあと、同じグループ（タグ）のゲストに、ニックネーム・アイコンと並べてランキングで見えます。承認の前は、ご本人だけです |
| 顔の検出の結果 | 新郎新婦だけ |

写真の URL は、推測しにくい文字列にしていますが、URL を知っている人は、ログインせずに開けます。ほかの方が写っている写真を、本サイトの外に転載しないでください。

#### 5. 外部のサービスの利用

本サイトは、次の外部のサービスを使って運営しています。お預かりした情報は、これらのサービスの設備に保存・送信されます。一部は、日本の外（米国など）にある設備です。

| サービス（会社） | 用途 | 送られる・保存される情報 |
|---|---|---|
| LINE ログイン（LINE ヤフー株式会社） | ログイン | ログインの確認のための情報 |
| Firebase・Google Cloud（Google） | データベース、ログインの管理、記録の保管 | 2 の情報のほぼすべて（写真・動画のファイルを除く）。データベースは日本（東京）に置いています |
| Cloudflare | 写真・動画の保管と配信 | 写真・動画 |
| Amazon Web Services（Amazon Rekognition） | 写真の顔の検出と照合 | 写真、顔の特徴のデータ |
| Vercel | サイトの配信 | 通信の内容（保存はしません）、接続の記録 |
| Sentry | エラーの検知 | エラーの記録（お名前・ご回答の内容・IP アドレスは送りません） |
| 【Vertex AI（Google）・Modal ― ゲスト向けの AI・音声の機能を公開する場合に書く。いまは新郎新婦の試験用だけ】 | | |

【会場の運営会社などに情報を渡す場合は、渡す先・項目・目的をここに書く。渡さないなら「上のほかに、第三者に提供することはありません（法令にもとづく場合を除きます）」】

#### 6. 保存する期間

【次のどれかに決めて書く】

- 【案 A】お預かりした情報は、披露宴の【N か月】後（【日付】）までに削除します。写真を残したい方は、それまでに保存してください。
- 【案 B】アレルギー・備考・顔のデータ・原本の写真は、披露宴の【1 か月】後までに削除します。投稿された写真とメッセージは、【日付】まで残し、その後に削除します。

削除したあとも、次のものは一定の期間、残ります。

- バックアップ: 最長 14 週間（期間が過ぎると自動的に消えます）
- 操作の記録: 400 日間（お名前やご回答の内容は含みません。改ざんを防ぐため、この期間は消せない設定にしています）

#### 7. 安全のための取り組み

- 招待した方だけが、LINE のログインとパスコードを通って利用できます。承認されるまで、ほかのゲストの情報は見えません。
- お名前・アレルギーなどは、ご本人と新郎新婦だけが読める場所に分けて保管しています。
- 通信は暗号化しています。操作の記録を残し、不正な利用を調べられるようにしています。
- 情報の漏えいなどが起きたときは、すみやかに、影響のある方へお知らせします。

#### 8. ご自身の情報の確認・訂正・削除

- **確認・訂正:** ご回答の内容（お名前・出欠・アレルギー・備考）は、【案内のページの「ご回答の変更」】から、いつでも確認・変更できます。ニックネームとアイコンは、設定の画面から変更できます。
- **投稿の削除:** ご自身の投稿とコメントは、画面から削除できます。削除すると、ほかの方に見える写真のファイルも消えます（配信の仕組みの都合で、しばらくのあいだ表示できる場合があります）。高画質の原本は、非公開の場所に残ります。原本まで消したいときは、9 の窓口までお知らせください。
- **すべての削除・そのほかのご依頼:** 9 の窓口までお知らせください。ご本人であることを確認したうえで、対応します。ご自身が写っている、ほかの方の投稿についても、ご相談ください。
- すでにほかの方が保存した写真は、私たちからは消せません。

#### 9. お問い合わせ先

【問い合わせ先。例: メールアドレス、または「新郎新婦の LINE まで」】

#### 10. 変更

内容を変えるときは、本サイトでお知らせします。
